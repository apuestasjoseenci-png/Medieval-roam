Medieval Roam v0.0.17 — cartografía estilizada

Basado en v0.0.16.
- Las teselas de OpenStreetMap se recolorean en el navegador con una paleta medieval: caminos ocres, vegetación verde y agua azul apagado.
- Mantiene la geometría REAL de las calles de las teselas incluso si los servidores Overpass fallan.
- Si Overpass responde, se superponen los caminos 3D existentes.
- Conserva GPS, aldea, recursos y respawn de 3 horas.

Limitación: la cartografía estilizada es una textura 2D colocada sobre terreno 3D, no una malla vectorial medieval completa. Requiere conexión a OpenStreetMap.
