Medieval Roam v0.0.10

Actualización sobre v0.0.9. Solicita automáticamente GPS al cargar, y centra el mapa en la primera posición real. No muestra un mapa genérico mientras espera ubicación. Si Safari bloquea la solicitud, se puede reintentar con el botón GPS. Safari/iOS puede exigir una interacción del usuario para mostrar el permiso; en ese caso pulsa GPS. Requiere HTTPS y servicios de localización habilitados.

Sube todos los archivos del ZIP a la raíz de tu repositorio GitHub Pages, manteniendo carpetas.
