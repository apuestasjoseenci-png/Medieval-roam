# Medieval Roam v0.0.23

Base estable: v0.0.22, sin modificar.

- Los nodos de madera, piedra, alimentos y mineral dan 5 unidades por recolección (antes 1).
- Se mantienen 50 metros de alcance y respawn individual cada 3 horas.
- El filtro de mosaicos OSM conserva los contrastes y líneas del mapa original en lugar de reducir casi todos los píxeles a tonos marrones planos.
- Mantiene el indicador de versión, el GPS y la aldea.

La mejora de color requiere comprobación visual en Safari iOS. La disponibilidad de caminos vectoriales sigue dependiendo de OSM/Overpass.
