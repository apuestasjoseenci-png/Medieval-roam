# Medieval Roam v0.0.13

Corrección de caminos reales: consulta de calles/senderos a OpenStreetMap mediante varios servidores Overpass, con diagnóstico de conexión y caché de sector. El mapa 3D necesita internet para descargar los trazados. Mantiene GPS automático, nodos (+1 y respawn a las 3 horas) y aldea.

Sube todo el contenido del ZIP a la raíz del repositorio GitHub Pages. En iPhone cierra y vuelve a abrir la app para activar la actualización del service worker.
